# Account Management Test Plan

This plan describes the behavior implemented by the current COBOL account-management program. Unless a test says otherwise, start a fresh program process before testing; the account starts at `1000.00`, and its balance is held only in memory. For sequential-operation tests, keep the same process running. Record observed output in **Actual Result** and change **Status (Pass/Fail)** from `Not Run` after execution. Cases marked as characterization or stakeholder decision capture behavior that the code does not define as a business rule.
